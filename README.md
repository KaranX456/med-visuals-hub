# Health Companion Portal

Using the attached project reference as the source of truth, design and build the complete frontend of the AI Health Companion & Clinical Decision Support application. Use React, Vite, TypeScript, and Tailwind CSS. Create a modern, responsive, healthcare-grade UI with intuitive navigation, reusable components, interactive dashboards, charts, graphs, timelines, and beautiful data visualizations where appropriate. Implement all patient, doctor, and admin screens described in the project document, using realistic mock data only. Focus on a polished, production-quality frontend with light/dark mode, accessibility, and an excellent user experience.
